# RestaurantIQ Website

Static project walkthrough site for the RestaurantIQ analytics project.

## Deploy to Vercel

Upload `index.html` and `style.css` to the GitHub repository connected to Vercel.

No build step is required.

## Update later

- Replace the demo button/link when the Streamlit portal is deployed.
- Add real Power BI screenshots when the dashboard is ready.
- Add the GitHub repository URL.
- Add a live Streamlit URL.

## Screenshot

Add the Streamlit screenshot manually as:

`streamlit.jpg`

in the same folder as `index.html`.

## Power BI

The **View Power BI Dashboard** button currently points to the Power BI site. Replace that URL in `index.html` with the final published Power BI report URL once the dashboard is ready.
